# CERN-Dimuon-Resonance-Analysis
Reconstruction and analysis of dimuon invariant mass spectra using CERN Open Data and Python.

## About the Project

I have always been interested in understanding how particle physics experiments help us study the fundamental particles of nature. Since my academic background is in Physics and I am currently pursuing a Master's in Data Science, I wanted to work on a project that combines both fields.

In this project, I used publicly available data from CERN to study dimuon events and their invariant mass distribution. The main idea was to understand how we can identify particles such as the Z boson by analyzing the particles produced during high-energy collisions.

The project gave me an opportunity to apply Python and data analysis techniques to real experimental physics data.

## Results and Observations

One of the main goals of this project was to investigate the invariant mass distribution of muon pairs and identify the region associated with the Z boson.

The analysis helped me understand how experimental measurements can be used to study particles that cannot be observed directly.

It was also interesting to see how concepts from relativistic physics connect with practical data analysis and visualization.

## Dataset
